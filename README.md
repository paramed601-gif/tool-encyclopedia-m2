# สารานุกรมเครื่องมือช่าง ม.2

เว็บไซต์สื่อประกอบการเรียนรู้ รายวิชาการงานอาชีพ ระดับชั้นมัธยมศึกษาปีที่ 2

## เนื้อหา
- เครื่องมือช่าง 12 ประเภท พร้อมคำอธิบายหน้าที่
- ค้นหาด้วยชื่อเครื่องมือหรือคำที่เกี่ยวข้อง
- เลือกดูตามหมวดช่าง
- อุปกรณ์ป้องกันอันตรายส่วนบุคคลและหลักความปลอดภัย

## เปิดใช้งาน
เว็บไซต์เป็น static site อยู่ใน `index.html` ข้อมูล 12 หมวดถูกบีบอัดฝังไว้ในหน้าเว็บเพื่อให้ใช้งานได้โดยไม่ต้องพึ่งไฟล์หรือฐานข้อมูลภายนอก นอกจากฟอนต์ระบบแล้ว หน้าเว็บไม่จำเป็นต้องใช้เซิร์ฟเวอร์ backend

## เผยแพร่ด้วย GitHub Pages
มี workflow ที่ `.github/workflows/pages.yml` สำหรับ deploy อัตโนมัติเมื่อ push ไปยัง `main` หรือสั่งรันเองจาก Actions
ในกรณีที่ GitHub Pages ยังไม่ถูกเปิดใช้งาน ให้เข้า Settings > Pages แล้วเลือก Source เป็น **GitHub Actions** จากนั้นตรวจสอบแท็บ Actions จน workflow สำเร็จ

## หมายเหตุ
ภาพบนการ์ดเครื่องมือเป็นสัญลักษณ์/อีโมจิประกอบ ไม่ใช่ภาพถ่ายจริงของเครื่องมือแต่ละรุ่น
